# 🦎 Axolotl Donate

Minecraft donate svetainė su Axolotl tematika.

## Paleidimas

Reikalingas Node.js 20 arba naujesnis.

Projekto aplanke paleisk:

npm install

Tada:

npm start

Svetainė:

http://localhost:3000

Admin:

http://localhost:3000/admin.html

Admin slaptažodis:

axolotl123

## Funkcijos

- Axolotl dizainas
- VIP
- MVP
- ELITE
- Minecraft nick įvedimas
- Demo užsakymų sistema
- Admin panelė
- Užsakymų saugojimas
- Responsive dizainas
